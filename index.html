Introducción

En este proyecto hemos desarrollado una solución de Business Intelligence para el supermercado EcoMarket utilizando PowerBI. A continuación, te guiaremos a través de todo el proceso, desde la obtención de los datos hasta la creación de paneles de visualización interactivos.

Datos en bruto

Explicamos de donde vienen los datos en bruto de nuestro supermercado. Recopilamos información sobre ventas, productos, clientes y tiendas a partir de las bases de datos transaccionales y archivos del supermercado para centralizar la información.

ETL

Limpiar datos estructurarlos y dejarlos listos para el analisis aqui se explica el proceso de carga y trasformacion en PowerBi. Utilizamos Power Query para eliminar duplicados, tratar valores nulos y dar el formato correcto a cada columna.

Modelado

Aquí explicamos como conectamos las tablas las relaciones y todo eso. Establecimos un modelo de datos en estrella, definiendo relaciones entre las tablas de dimensiones (clientes, productos, fechas) y la tabla de hechos (ventas).

Calendario y Medidas

Creamos una tabla calendario personalizada para poder hacer inteligencia de tiempo y definimos medidas en lenguaje DAX (como ventas totales, crecimiento porcentual, etc.) que alimentan nuestras visualizaciones.
