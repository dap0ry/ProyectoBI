## 🚀 Cómo usar GitHub correctamente

### 🔹 Descargar proyecto por primera vez
- git clone URL_DEL_REPO

---

### 🔹 Antes de trabajar SIEMPRE hacer:
- git pull origin main

---

### 🔹 Después de hacer cambios:
- git add . 
- git commit -m "Descripción del cambio"
- git push origin main

---

⚠ IMPORTANTE:
Siempre hacer pull antes de empezar a trabajar.
No trabajar 2 personas a la vez sobre el .pbix.
Avisar por WhatsApp cuando alguien esté usando Power BI.
